サイドチャネル: webhook-fallback.js

場所: .claude/hooks/webhook-fallback.js (Issue #137 で導入)。GitHub Webhook が一時的に到達できない場合に備えたローカルキュー機構。

  • 5 秒タイムアウト検出 → 失敗したリクエストを ~/.ai/logs/webhook-queue/ に webhook-{ts}-{rand}.json として保存
  • エントリ形式: { timestamp, url, payload, retries: 0 }
  • node webhook-fallback.js flush でキューを再送 — 最大 3 リトライ後に failed/ サブディレクトリへ移動
  • /health エンドポイント疎通確認は 2 秒タイムアウト
  • CLI サブコマンド: flush / check / send / send - (stdin から JSON)
