🎯 Critical Path 計算 (DP)

CoordinatorAgent.ts 行171-215

トポロジカルソート後、動的計画法で最長経路を計算。

topologicalSort() 行217-249 (Kahn's algorithm)

結果: [task-1, task-2, task-3, task-4, task-5]

DP計算 (maxDistance Map)

task-1: 0 + 30 = 30   (predecessor: null)
task-2: 30 + 60 = 90  (predecessor: task-1)
task-3: 30 + 45 = 75  (predecessor: task-1)
task-4: max(90,75) + 30 = 120  (predecessor: task-2)
task-5: 120 + 10 = 130  (predecessor: task-4)

Critical Path 逆トレース (行207-214)

task-5 → task-4 → task-2 → task-1 → 反転 → Critical Path = [task-1, task-2, task-4, task-5] (130分)

Task-3 の slack: 15分 (90 - 75) — 遅延しても全体に影響なし

ガントチャート可視化

★ = Critical Path 上のタスク

🎯 ReviewAgent.review() — 80点ゲート

packages/miyabi-agent-sdk/src/agents/ReviewAgent.ts 行73-215

生成コードを複数軸で評価し、80点未満なら提案付きで差戻し。

品質スコア計算式 (行304-321)

staticScore   = 40 - (errorCount × 10 + warningCount × 2)  // 最大40点
securityScore = passed ? 30 : 0                              // 30点
coverageScore = min(30, coverage% / 80 × 30)                // 30点
──────────────────────────────────────────────────
totalScore    = max(0, min(100, static + security + coverage))

80点ゲート判定 (行187)

passed = qualityScore >= input.standards.minQualityScore  // default 80

ガントチャート機能の想定スコア: 88点 (static 36 + security 30 + coverage 22)

失敗時 (generateSuggestions 行323-361)

  • "Fix N static analysis errors"
  • "Increase test coverage from X% to 80%"
  • "Quality score is N points below threshold"
  • CodeGenAgent 自動再生成 (最大3回)
