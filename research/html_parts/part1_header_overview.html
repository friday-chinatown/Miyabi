Miyabiとは？

Miyabi（雅）は、あなたの代わりにプログラミングをしてくれるAIシステムです。

普通のソフトウェア開発では、エンジニアがコードを書いて、テストして、レビューして、サーバーにアップロード（デプロイ）します。 Miyabiを使うと、これらの作業を⚡ 全部AIが自動でやってくれます。

💡 わかりやすいたとえ

レストランに例えると...
あなたは「カレーが食べたい」とメニューに書くだけ（= Issue作成）。
すると、料理長（CoordinatorAgent）が指示を出し、
調理担当（CodeGenAgent）が料理を作り、
味見係（ReviewAgent）が品質をチェックし、
配膳係（DeploymentAgent）がテーブルに届けてくれます。
あなたは注文するだけ。あとは全自動。

Windows 95がパソコンを、iPhoneがスマホを「誰でも使えるもの」に変えたように、
MiyabiはAI開発を🌱 誰でも使えるものに変えます。

⚖️ 自律の三法則

MiyabiのすべてのAIエージェントは、この3つの法則に従って動きます。
これはAIが「暴走」しないためのルールブックです。

01
📊

第一法則

客観性の法則（Objectivity）

AIは「なんとなく」で判断しません。すべての判断はデータと数字に基づいて行います。 感情や気分に左右されず、常に冷静に数字で評価します。

👉 具体的には
コードの品質を0〜100点で採点し、80点以上でないと合格にしません。 「なんとなく良さそう」ではなく「87点だから合格」と判断します。
02
⚡

第二法則

自給自足の法則（Self-Sufficiency）

AIはできるだけ人間に頼らず、自分で問題を解決します。 失敗しても最大3回自動でやり直し、本当にダメなときだけ人間に助けを求めます。

👉 具体的には
人間が介入する割合を5%以下に抑えることが目標。 コードが不合格なら自動で修正を試み、3回やり直してもダメな場合だけ人間にエスカレーションします。
03
📝

第三法則

追跡可能性の法則（Traceability）

AIのすべての行動は記録に残ります。 何をしたか、なぜそうしたかが全部GitHubに記録されるので、後から確認できます。

👉 具体的には
すべてのログは .ai/logs/ に日付ごとに保存。 AIの判断理由もIssueのコメントに記録。「ブラックボックス」にはなりません。

🖥️ GitHub = オペレーティングシステム

パソコンにはWindowsやmacOSという「OS」がありますよね。
MiyabiはGitHub自体をAI開発用のOSとして使います。
GitHubの既存機能を、まるでOSのパーツのように活用するアイデアです。

🛠️ 技術スタック

Miyabiを構成する技術たち。
それぞれの技術が何をしているのか、簡単に紹介します。

📜

言語とランタイム

Miyabiは主にTypeScriptで書かれています。TypeScriptは「型」があるJavaScriptで、間違いを事前に防げます。

  • TypeScript Strict モード / ES2022
  • Node.js v18+ ランタイム
  • pnpm 9 パッケージ管理
  • Python コンテキスト最適化用
🤖

AI / エージェント基盤

AIの頭脳であるClaude APIと、エージェント間の通信プロトコルMCPが核心技術です。

  • Anthropic SDK Claude Sonnet 4
  • MCP SDK 172+ 統合ツール
  • Agent Skill Bus 110+ スキル
🐙

GitHub統合

GitHubのAPIを使って、Issue、PR、Projects、Actionsを自動操作します。

  • Octokit REST GitHub REST API
  • Octokit GraphQL 高度なクエリ
  • Actions 16+ ワークフロー
  • Webhooks リアルタイム連携
✅

テスト / 品質管理

コードの品質を自動で保証する仕組み。テスト、型チェック、コード規約を自動実行します。

  • Vitest ユニット / 統合テスト
  • Playwright E2E ブラウザテスト
  • ESLint コード規約チェック
  • TypeScript 型安全性検証
💻

CLI / ユーザーインターフェース

ターミナル（黒い画面）で美しく操作できるコマンドラインツールです。25以上のコマンドを搭載。

  • Commander.js コマンド体系
  • chalk 色付きテキスト
  • ora ローディングアニメ
  • Next.js 15 Web ダッシュボード
📦

インフラ / DevOps

コンテナ技術で、どの環境でも同じように動くことを保証します。分散実行にも対応。

  • Docker コンテナ化
  • PostgreSQL データ永続化
  • Redis キャッシュ / 座標
  • Tailscale 分散クラスター
