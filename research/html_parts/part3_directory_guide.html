📄 ルートファイル（27ファイル） ― プロジェクト全体の設定
ファイル名 何をするファイル？ なぜ必要？
package.json プロジェクト全体の設定。名前、バージョン（0.22.0）、140+のnpmスクリプトを定義 Node.jsが「このプロジェクトは何か」を理解するための必須ファイル
pnpm-workspace.yaml 「packages/*」をモノレポとして管理する宣言 11パッケージを1つのリポジトリで効率的に管理するため
tsconfig.json TypeScriptコンパイラの全体設定（ES2022、strict mode） 型安全なコードを書くためのTypeScript必須設定
CLAUDE.md Claude Code AIへの指示書。プロジェクトのルール・知識を記述 AIがこのプロジェクトを正しく理解して作業するため
vitest.config.ts テストフレームワーク Vitest の設定。workspace projects定義 テストの実行方法・対象を統一的に管理
playwright.config.ts ブラウザE2Eテスト（Playwright）の設定 ダッシュボード等のUIを自動テストするため
Dockerfile Dockerコンテナのビルド手順。マルチステージビルド（4段階） どの環境でも同じように動くコンテナを作るため
docker-compose.yml 複数サービスの一括起動設定 開発環境を docker-compose up 一発で起動
.env.example 環境変数のテンプレート（APIキー等の雛形） 実際の .env はGitに入れないので、見本として必要
.gitignore Gitで追跡しないファイルの一覧（node_modules、dist、.env等） 不要ファイルや秘密情報をリポジトリに入れない
.eslintrc.json / .eslintignore コード品質チェックツール（ESLint）の設定 コードスタイルを統一し、バグを防ぐ
.gitleaks.toml シークレット漏洩検出ツールの設定 APIキーやパスワードの誤コミットを防止
CODEOWNERS 各ディレクトリのコードオーナーを定義 PRレビューの自動割り当て
BUDGET.yml AI APIの使用予算設定 Claude API等のコストを管理
LICENSE / NOTICE / SECURITY.md ライセンス、帰属情報、セキュリティポリシー OSSとしての法的・安全性情報
.miyabi.yml.example Miyabi設定ファイルのテンプレート ユーザーが自分の .miyabi.yml を作る参考に
📦 packages/ ― 11個のTypeScriptパッケージ（プロジェクトの心臓部）

モノレポ構造: 1つのリポジトリの中に11個の独立パッケージがある。pnpmのworkspace機能で連携管理。
初心者は最初に cli（コマンドライン）、core（基盤）、coding-agents（AIエージェント群）の3つを理解すれば十分です。

🌐 miyabi_def/ ― SWML定義・世界モデル（学術的基盤）

何をするの？ Shunsuke World Model Logic（SWML）の定義。Miyabiの理論的・数学的基盤。Jinja2テンプレート + YAML変数によるコード生成パイプライン。

templates/（12ファイル）
Jinja2テンプレート: agents, entities, workflows, world_definition, skills, labels等
variables/（15ファイル）
YAML変数: agents, entities, workflows, labels, skills, naming_conventions等
diagrams/（12ファイル）
PlantUML図: system_architecture, data_flow, agents, execution_category等
学術論文: SWML_PAPER.pdf / .tex（英語・日本語）
コード生成: generate.py / generate_puml.py（テンプレート→YAML→出力）
🚀 workflow-automation/ ― Pythonワークフロー自動化

何をするの？ Python製のワークフロー自動化システム。SEOブログ生成、スクレイピング、SERP分析等のエージェント。TypeScript側とは独立して動作。

app.py .................. メインアプリケーション
agents/ ................. content_generator.py, scraper_agent.py, serp_agent.py
core/ ................... entity_mapping.py, workflow_architecture.py, stream_processor.py
workflows/ .............. run_daily_ops.py（日次運用）
examples/ ............... seo_blog_generator.py
society/core/ ........... orchestrator.py（ソサエティオーケストレーター）
config/ ................. workflow_config.yaml
requirements.txt ........ Python依存関係
