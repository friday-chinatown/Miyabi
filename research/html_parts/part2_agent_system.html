02 21体のAIエージェント

Miyabi を支える、個性豊かな21人のなかまたち

Miyabi には 21体のAIエージェント がいます。それぞれにかわいい日本語の名前と専門のお仕事があります。

大きく分けると コーディングチーム（7体） と ビジネスチーム（14体） の2グループ。まるで会社のように、リーダーがいて、実行役がいて、分析役がいて、サポート役がいる -- そんなチームワークで動いています。

役割カラーシステム

エージェントの色は「どんな役割か」を表しています。信号みたいなものですね。

リーダー 🔴
赤 = リーダー（2体）

チーム全体をまとめる司令塔。同時に1つしか動けない（排他実行）

実行役 🟢
緑 = 実行役（12体）

実際に手を動かす主力メンバー。最大5体が同時に並列で動ける

分析役 🔵
青 = 分析役（5体）

調べたり、チェックしたり、評価したりする頭脳派。並列で動ける

サポート 🟡
黄 = サポート（3体）

前の工程が終わってから動く縁の下の力持ち（条件付き実行）

💻 コーディングチーム（7体）

ソフトウェア開発を自動でこなすチーム。Issue（課題）を受け取って、コードを書いて、チェックして、本番環境に届けるまでを担当します。

CoordinatorAgent

コーディングチームの司令塔。大きな仕事を小さなタスクに分解して、誰に何をやらせるか決める「仕切り屋さん」。DAG（有向非巡回グラフ）という図を作って、効率的にみんなを動かします。

お仕事 タスク分解 / チーム指揮 / 進捗監視
すごいところ 最大5体を同時に動かせる
DAG生成 <30秒 分解精度 >95% 並列効率 >70%

つくるん

AIの力でコードを自動生成するエンジニア。Claude Sonnet 4を使って、TypeScriptのコードだけでなく、テストコードやドキュメントコメントも一緒に作ってくれます。

お仕事 コード生成 / テスト自動作成 / 型定義追加
使用AI Claude Sonnet 4（最大8,000トークン）
生成時間 <60秒 品質 >80/100 テストカバレッジ >80%

めだまん

ReviewAgent
🔵 分析役

コードの品質を100点満点でスコアリングする「目」の番人。型安全性、テストカバレッジ、lint準拠、ドキュメントの4つの観点で厳しくチェック。80点未満なら「もう一回やり直し！」と差し戻します。

お仕事 品質チェック / スコアリング / 差し戻し判定
採点基準 型安全30% + テスト30% + lint20% + ドキュメント20%
レビュー <90秒 問題検出率 >90% 偽陽性 <10%

お仕事 Issue分析 / 53ラベル自動分類 / 重複検出

PRAgent

レビューに合格したコードをPull Request（PR）にまとめる取りまとめ役。Conventional Commits形式（feat, fix, refactor...）で整ったPRを自動で作ってくれます。

お仕事 PR自動作成 / コミットメッセージ生成

エージェント同士の会話のしくみ

エージェントたちは「メッセージバス」という共通の連絡網で会話します。手紙のやり取りのようなイメージです。

🎯 しきるん （司令塔）
TASK_ASSIGNMENT
「このタスクをお願い！」
MessageBus（連絡網）
タスク割り当て 状況報告 エスカレーション 結果報告 エラー報告 ヘルスチェック
メッセージ配信
🛠️ つくるん
👁️ めだまん
📋 まとめるん
🚀 はこぶん
STATUS_UPDATE / RESULT_REPORT
「できました！」「問題発生！」

メッセージの中身はこうなっている

id 一意のID（UUID形式） 手紙の管理番号のようなもの
from 送信者（例: CoordinatorAgent） 誰からの手紙か
to 受信者（例: CodeGenAgent） 誰への手紙か
type 種類（TASK_ASSIGNMENT など） 手紙の用件
priority 0~3（0=最重要） どれくらい急ぎか
payload 具体的な内容データ 手紙の本文

キャラクター命名システム：名前に込められた意味

21体のエージェントの名前は、すべて「何をするか」がわかるように工夫されています。非エンジニアでも親しみやすい、日本語ならではのネーミングです。

1
ひらがな・カタカナ優先

漢字は最小限。だれでも読みやすく

2
役割を表現

「つくる」=create、「めだ」=eye（目）、「しきる」=coordinate

3
親しみやすい接尾辞

〜くん、〜ちゃん、〜るん、〜さん で友だちみたいに

4
3~5文字

短くて覚えやすい。声に出して呼びたくなる長さ
