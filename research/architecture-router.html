🎯 Agent 4層フォールバック実装

CodeGenAgent と ReviewAgent は以下の4モードを順次試行。各モードが失敗すると次へフォールスルー、最後は必ず Mock で返る。

CodeGenAgent.ts

Mode 0Codex CLI行192-211

★ 最優先・コーディング特化。try/catch でラップされ失敗時は空 catch → 次モードへ自動フォールスルー。

if (useRealAPI && codexClient) {
  try {
    const result = await codexClient.generateCode({...});
    return { files, tests, qualityScore, cost: 0 };
  } catch {
    // Codex failed, fall through to Claude Code
  }
}
Mode 1Claude Code CLI行213-229

$0 ローカル実行。try/catch なし — 意図的に例外を上位に伝播させる（上位 generate() メソッドの try/catch でキャッチ）。

if (useRealAPI && claudeCodeClient) {
  const result = await claudeCodeClient.generateCode({...});
  return { files, tests, qualityScore, cost: 0 };
}
Mode 2Anthropic API行231-247

有料API。実トークン数とコストを calculateCost() で計算。

if (useRealAPI && anthropicClient) {
  const result = await anthropicClient.generateCode(...);
  const cost = anthropicClient.calculateCost(result.tokensUsed);
  return { ..., tokensUsed: result.tokensUsed, cost };
}
Mode 3Mock テンプレート行249-258, 291-322

必ず成功。言語別スタブ（TypeScript / Rust / Python）を返す。

// 言語別テンプレート
{
  typescript: "export class GeneratedClass { ... TODO ... }",
  rust:       "pub struct GeneratedStruct; ...",
  python:     "class GeneratedClass: ...",
}

ReviewAgent.ts

Mode 0Codex CLI (レビュー特化)行82-111

try/catch で失敗時次へ。codexClient.reviewCode(files) + カバレッジ測定。

Mode 1Claude Code CLI行113-138

ClaudeCodeClient.reviewCode + カバレッジ。

Mode 2Anthropic API行140-162

AnthropicClient.reviewCode + 実コスト計算。

Mode 3Mock 静的解析行164-207

実際の簡易静的解析を並列実行：

  • runStaticAnalysis() — ファイル名"bad"検出, 1000字超警告
  • runSecurityScan() — password/api_key/secret/token/private_key パターン検出
  • checkCoverage() — .test. ファイル比率計算
  • calculateQualityScore() — 静的40点+セキュリティ30点+カバレッジ30点
  • generateSuggestions() — 条件別改善提案生成
